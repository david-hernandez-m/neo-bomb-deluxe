# Neo Bomb Deluxe - Improved

Neo Bomb Deluxe es un videojuego 2D desarrollado en Python utilizando la librería Pygame. El proyecto está inspirado en la mecánica clásica de juegos tipo Bomberman, incorporando niveles progresivos, enemigos, bombas, power-ups, jefes, sistema de puntuación, guardado de récords y soporte visual mediante sprites personalizados.

## Descripción del proyecto

El objetivo del juego es controlar al personaje principal, colocar bombas estratégicamente, eliminar enemigos, encontrar la salida y avanzar por distintos niveles. A medida que el jugador progresa, la dificultad aumenta mediante la aparición de enemigos más rápidos, enemigos tipo fantasma y niveles especiales con jefe.

El proyecto incluye:

- Juego principal desarrollado con Pygame.
- Sistema de niveles progresivos.
- Dificultades seleccionables: fácil, normal y difícil.
- Sistema de puntuación y récord.
- Guardado automático del mejor puntaje y mejor nivel alcanzado.
- Power-ups para mejorar al jugador.
- Enemigos con distintos comportamientos.
- Niveles de jefe cada cierto avance.
- Visor de assets para comprobar imágenes del juego.
